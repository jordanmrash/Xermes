# Lessons corpus

`lessons.md` is the host-agnostic lessons corpus: failed approaches and what
worked instead, one entry per Pattern-Key.

- **Format and rules:** see the `evidence-gated-lessons` skill — the corpus is
  data for that skill, and the skill is the format spec.
- **Provenance:** seeded 2026-11-15 from `agent-of-record`
  (`CoworkConfig/cowork-memory/cowork-lessons.md`, 45 of its 120 entries —
  only the host-agnostic ones); subsequent entries are host-agnostic lessons
  logged by the Hermes instance under the same format.
- **Hygiene:** entries are sanitized before publication (see SECURITY.md);
  superseded entries are marked, never deleted.
